# voucher-pwa
Mobile Voucher Progressive Web App

📌 Project Rules

  Branching
  - main → production only
  - dev → development branch
  - feature branches:
      - feature/auth
      - feature/vouchers
      - feature/redeem

   Workflow
   - Create branch
   - Code feature
   - Push branch
   - Create Pull Request → dev
   - Review required before merge


  Rules:
  - No direct commits to main
  - No breaking dev
  - All features must be independant
  - Each feature must include frontend + backend logic
